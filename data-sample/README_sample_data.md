# sample_llm_logs.csv

이 파일은 프로젝트 데모를 위해 생성한 합성 데이터입니다.

- 실제 개인정보, 실제 기업 로그, 실제 API Key, 실제 고객정보는 포함되어 있지 않습니다.
- 민감정보처럼 보이는 값은 마스킹 기능 테스트를 위한 가짜 샘플입니다.
- `example.invalid`, `010-0000-0000`, `가상고객A`, `API_KEY_SAMPLE_DO_NOT_USE_0000` 등은 모두 데모용 합성 문자열입니다.
- `cost`는 실제 Azure/OpenAI 과금표가 아니라 프로젝트 테스트용 가상 비용입니다.
- 분석 결과 컬럼인 `masked_prompt`, `task_label`, `risk_score`, `opportunity_score` 등은 CSV에 미리 넣지 않았습니다. 서비스가 분석 후 생성해야 하는 값입니다.

## 컬럼

| 컬럼명 | 타입 예시 | 의미 | 서비스에서 활용 |
|---|---|---|---|
| `log_id` | `1`, `2450` | 각 로그를 식별하는 고유 ID | 업로드 데이터 중복 확인, 상세 로그 조회, 처리 결과 매핑 |
| `department` | `마케팅팀`, `개발팀`, `재무/기획팀` | LLM을 사용한 사용자가 속한 부서 | 부서별 사용량, 비용, Risk, 자동화 후보 집계 |
| `user_hash` | `user_mkt_06` | 개인을 직접 식별하지 않도록 처리한 사용자 ID | 부서 내 고유 사용자 수 계산, 다수 사용자 여부 판단 |
| `prompt_text` | `전환율 데이터를 보고...` | 사용자가 LLM에 입력한 원문 프롬프트 | 마스킹, 민감정보 탐지, 업무 유형 분류, 임베딩, 군집화의 핵심 입력 |
| `model` | `gpt-4o-mini`, `gpt-4o`, `gpt-4.1-mini` | 사용된 LLM 모델명 | 모델별 사용량/비용 분석, 고비용 모델 사용 패턴 확인 |
| `input_tokens` | `706` | 프롬프트 입력에 사용된 토큰 수 | 입력 사용량 분석, 비용 계산 검증 |
| `output_tokens` | `1076` | 모델 응답 생성에 사용된 토큰 수 | 출력 사용량 분석, 답변 길이 패턴 분석 |
| `total_tokens` | `1782` | 입력 토큰과 출력 토큰의 합계 | 전체 사용량 집계, 부서별 토큰 사용량 분석 |
| `cost` | `26.55` | 해당 요청의 가상 비용 | 부서별 비용, 모델별 비용, 자동화 기회 점수 계산 |
| `created_at` | `2026-05-04 10:24:00` | 로그가 생성된 시각 | 일별/주별/월별 트렌드, 시간대별 사용 패턴 분석 |
